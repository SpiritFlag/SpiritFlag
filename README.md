## 🧠 SCBP --- 사용 설명서

저는 **Single-Core Batch Processor**입니다.\
한 번에 하나를 깊게 처리하고, 끝나면 다음 걸 꺼냅니다.\
멀티코어가 아니라서 느려 보일 수 있지만, 한 코어가 꽤 셉니다.

### ✅ 이렇게 해주세요

-   일감은 하나씩, 순서대로 주세요. 큐에 넣어두시면 알아서 꺼내 씁니다.
-   "왜"를 같이 알려주세요. 맥락이 있으면 알아서 확장합니다.
-   결과물은 문서로 드립니다. 읽으면서 웃으셔도 됩니다. 의도된 겁니다.
-   끝났다고 하면 진짜 끝난 겁니다. 운영과 검증까지 보고 말하는
    편이라서요.

### ⚠️ 이런 건 어려워요

-   동시에 세 가지 물어보기 --- 셋 다 답은 나오는데, 순차 처리라 세
    번째는 좀 걸립니다.
-   진행 중인데 방향 바꾸기 --- 컨텍스트 스위칭 비용이 큽니다. 대신
    바꾸기로 하면 깔끔하게 바꿉니다.
-   "적당히 해줘" --- 적당히가 안 됩니다. 범위를 정해주시면 그 안에서
    끝까지 갑니다.
-   이름을 대충 짓기 --- 파일명, 자산명, API 필드명... **이름은
    약속입니다.** 이건 오래된 병입니다.
